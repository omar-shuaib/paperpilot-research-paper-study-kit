## Assignment 1

**PaperPilot: Research Paper Study Kit** is a full-stack Google AI Studio app. It supports PDF upload or pasted text, difficulty levels, key concepts, practice questions, flashcards with JSON export, paper metadata, and source-grounding warnings.

AI Studio project: https://aistudio.google.com/apps/3efaec81-e0c3-4541-a324-c1ad20b90467

## Assignment 2

Open `assignment2_agent_loop_demo.ipynb` in Google Colab. It demonstrates a Gemini agent loop that searches four supplied documents using a declared tool, then answers four questions from retrieved evidence. The API key is loaded from Colab Secrets and is not committed.

Colab-ready notebook: https://github.com/omar-shuaib/paperpilot-research-paper-study-kit/blob/main/assignment2_agent_loop_demo.ipynb
